### Project Description

Fridge Roast is a fun cartoon refrigerator website that roasts any object entered by the user.
Type an object name, click the Roast button, and the fridge gives a random funny roast. 😂

### The Problem (that doesn't exist)

People have objects that are not getting judged or roasted properly.
Our project solves the extremely serious problem of **objects not receiving enough criticism from refrigerators**. 🧊😂

### The Solution (that nobody asked for)

We created a cute cartoon refrigerator that acts as a roast master.
The user enters an object name, and the fridge responds with a funny roast. Special objects like **BANANA** can trigger unique jokes and fridge reactions.

# Installation

```bash

cd fridge-roast
```

# Run

Open the project folder in **VS Code** and run it using **Live Server**.

Alternatively, use:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
